# PowerPoint 製作

## 工具路由

- 使用環境提供的 Presentations 能力建立、編輯、渲染與檢查 `.pptx`。
- 使用內建 Imagegen 製作必要的主視覺或輔助圖片；不要要求 API Key。
- 使用原生 PowerPoint 文字、形狀、表格、圖表、公式與連接線維持可編輯性。
- 只在使用者明確要求時改用外部 CLI、API 或特定模型。

不要依賴固定的使用者目錄、Claude 路徑、工作階段路徑或未隨 Skill 提供的腳本。需要額外工具而環境沒有時，回報限制並採用可攜式替代方案。

## 建立流程

1. 在工作區 `output/` 建立本次產出資料夾。
2. 先建立空白骨架，確認頁數、順序、標題與頁面角色。
3. 完成三張代表頁，檢查字級、留白、色彩、圖片政策與複雜元件。
4. 套用一致的母片語言完成全稿。
5. 將講者補充放入備忘稿；畫面只保留理解所需資訊。
6. 渲染每頁並產生蒙太奇總覽。
7. 修正溢位、重疊、裁切、對比、圖表與幾何問題。
8. 再次渲染最終檔並交付。

## 原生元素選擇

| 內容 | 優先元素 |
|---|---|
| 精確文字 | 文字框 |
| 定義、步驟、比較 | 文字框＋原生形狀 |
| 數據 | 原生圖表或簡潔 SVG／向量圖 |
| 表格 | PowerPoint 表格 |
| 公式 | Office 方程式或可編輯數學物件 |
| 幾何 | 原生線段、圓、弧、標記與群組 |
| 情境、人物、主視覺 | Imagegen 或使用者圖片 |

不要把表格、公式、精確圖表或大量正文烘焙進圖片。

## 圖片政策

生成圖片前先寫一份視覺簡述，包含用途、主體、構圖、風格、色盤、留白區與禁止項目。需要疊加可編輯文字時，要求圖片不含文字並明確預留安全區域。

逐張檢查：

- 主體與教學意圖一致。
- 沒有非預期文字、Logo、浮水印或 UI。
- 風格、比例、色盤與光線一致。
- 不與標題、標註或操作區域衝突。

## 修改既有簡報

保留原始檔，另存新版本。先辨識母片、版型、字型、主題色、圖表資料與群組關係，再修改。不要把可編輯物件扁平化，也不要用整頁截圖覆蓋原頁。

若只修改少數頁，仍需渲染前後頁，確認轉場與整體風格沒有斷裂。
